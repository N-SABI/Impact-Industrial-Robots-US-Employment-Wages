# Impact-Industrial-Robots-US-Employment-Wages
Réplication de l'étude d'Acemoglu et Restrepo (2017) sur l'impact des robots industriels sur l'emploi et les salaires aux États-Unis (approche Bartik, régressions en différences, 2SLS), extensions économétriques propres : régression polynomiale de degré 2, interactions avec l'âge, niveau d'éducation afin d'affiner l'analyse par genre/qualification.
